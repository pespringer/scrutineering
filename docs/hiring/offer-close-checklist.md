# Offer-Close Checklist — Founding Engineer Hiring

**Effective:** 2026-04-05
**Owner:** CTO (recommending), CEO (approving per SCR-22 authority matrix)

## Pre-Offer Readiness

- [ ] All scorecards from interview loop are complete and submitted
  - Review: Check `docs/hiring/weekly-debrief-compliance-report.md` for SLA status
  - Blocker if any debrief is marked `overdue_open`
- [ ] Candidate disposition decision is unanimous or escalated to CTO
- [ ] Compensation band and level confirmed with CEO
- [ ] Competing offer intelligence gathered by recruiting ops
- [ ] Start-date window confirmed with candidate
- [ ] Any accommodation or equipment needs documented

## Reference Check Phase

- [ ] Reference request sent to candidate (minimum 3 references requested)
- [ ] At least 2 references completed and documented
- [ ] Reference findings aligned with interview scorecard signals
- [ ] Red flags (if any) reviewed by CTO before offer decision
- [ ] Reference package filed in candidate folder

## Offer Preparation

- [ ] Formal offer letter drafted with compensation, equity, start date
- [ ] Offer reviewed by CTO for role fit and compensation alignment
- [ ] Offer approved by CEO per authority matrix
- [ ] Legal review completed (if template deviates from standard)
- [ ] Offer delivery method confirmed (email, phone, platform)

## Offer Close

- [ ] Offer delivered to candidate with response deadline
- [ ] Response deadline: 5 business days from delivery
- [ ] Daily check-in scheduled with recruiter for status updates
- [ ] If accepted: onboarding plan triggered, team notified
- [ ] If declined: debrief on reasons, update sourcing strategy
- [ ] If counter-offer: CTO + CEO review within 24 hours

## Post-Offer

- [ ] Acceptance/decline recorded in pipeline tracker
- [ ] If accepted: equipment ordered, access provisioned, onboarding scheduled
- [ ] If declined: root cause analysis within 48 hours
- [ ] Pipeline health reviewed at next Friday calibration
